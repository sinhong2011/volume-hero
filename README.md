## ✨ Features

- 🔊 **Volume Boost** - Amplify volume up to 600% on any website
- 💾 **Per-site Memory** - Automatically remembers your preferred volume for each domain
- 🎯 **Auto-apply** - Automatically apply saved volume when revisiting a site
- 🌐 **Multi-language** - Supports English, Chinese, and Japanese
- 🎨 **Modern UI** - Clean interface with dark/light theme support
- 🚀 **Lightweight** - Minimal performance impact

## 🚀 Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (v1.3.3+) or [Node.js](https://nodejs.org/) (v18+)

### Installation

```bash
# Clone the repository
git clone https://github.com/user/volume-hero.git
cd volume-hero

# Install dependencies
bun install
```

### Development

```bash
# Start development server (Chrome)
bun run dev

# Start development server (Firefox)
bun run dev:firefox
```

### Build

```bash
# Build for Chrome
bun run build

# Build for Firefox
bun run build:firefox

# Create zip package for distribution
bun run zip
```
