## ✨ 功能特点

- 🔊 **音量增强** - 任意网站音量可增强至 600%
- 💾 **按站记忆** - 自动记住每个网站的音量偏好设置
- 🎯 **自动应用** - 重新访问网站时自动应用已保存的音量
- 🌐 **多语言支持** - 支持英语、中文、日语
- 🎨 **现代界面** - 简洁美观，支持深色/浅色主题
- 🚀 **轻量高效** - 对性能影响极小

## 🚀 快速开始

### 环境要求

- [Bun](https://bun.sh/)（v1.4.0+）或 [Node.js](https://nodejs.org/)（v18+）

### 安装

```bash
# 克隆仓库
git clone https://github.com/user/volume-hero.git
cd volume-hero

# 安装依赖
bun install
```

### 开发

```bash
# 启动开发服务器（Chrome）
bun run dev

# 启动开发服务器（Firefox）
bun run dev:firefox
```

### 构建

```bash
# 构建 Chrome 版本
bun run build

# 构建 Firefox 版本
bun run build:firefox

# 创建发布包
bun run zip
```
